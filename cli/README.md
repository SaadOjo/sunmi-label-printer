# ojo-print

CLI for agents/scripts to print to SUNMI/raw printers over TCP 9100.

## Install path

```bash
~/ojo-print-cli/ojo-print
~/bin/ojo-print   # symlink
```

If needed:

```bash
export PATH="$HOME/bin:$PATH"
```

## Protocols

- Transport: raw TCP/AppSocket/JetDirect, default port `9100`
- Receipts: ESC/POS
- Labels: TSPL
- Raw escape hatch: bytes/text/hex/base64 passthrough

Use ESC/POS for receipt paper, logos/images, QR, barcode, cutter, cash drawer.
Use TSPL for labels, exact size, x/y layout, barcode/QR, gap calibration.

## Commands

```bash
ojo-print doctor [--ip HOST] [--port 9100]
ojo-print discover --subnet 192.168.0.0/24
ojo-print status --ip HOST

ojo-print receipt --ip HOST [--json receipt.json]
ojo-print label --ip HOST [--json label.json]
ojo-print calibrate-label --ip HOST --width 50 --height 20 --gap 3

ojo-print job --json job.json [--ip HOST] [--preview]
ojo-print raw --ip HOST (--file f | --text s | --hex h | --base64 b)
ojo-print image --ip HOST --pbm image.pbm --max-width 576 [--cut]
ojo-print width-test --ip HOST --paper 80 --columns 48
ojo-print media
```

All normal results are JSON. Non-zero exit means failure.

## Examples

Connectivity:

```bash
ojo-print doctor --ip 192.168.0.50
ojo-print discover --subnet 192.168.0.0/24
```

Receipt sample:

```bash
ojo-print receipt --ip 192.168.0.50
```

Receipt JSON:

```json
{
  "paper": "80",
  "columns": 48,
  "storeName": "OJO Store",
  "orderNumber": "R-10042",
  "taxRate": 0.0825,
  "items": [
    { "name": "Coffee", "quantity": 2, "unitPrice": 3.5 }
  ],
  "barcode": "100420001234",
  "qr": "https://ojo.example/receipt/R-10042",
  "cut": true
}
```

Print it:

```bash
ojo-print receipt --ip 192.168.0.50 --json receipt.json
```

58mm receipt: use `"paper":"58"`, `"columns":32`.
80mm receipt: use `"paper":"80"`, `"columns":48`.

Label JSON:

```json
{
  "widthMM": 50,
  "heightMM": 20,
  "gapMM": 3,
  "speed": 3,
  "density": 12,
  "title": "OJO",
  "subtitle": "Thermal Label Roll",
  "price": "$8.99",
  "barcode": "SKU001234",
  "qr": "https://ojo.example/SKU001234"
}
```

Print it:

```bash
ojo-print label --ip 192.168.0.50 --json label.json
```

Calibrate after loading label media:

```bash
ojo-print calibrate-label --ip 192.168.0.50 --width 50 --height 20 --gap 3
```

Agent envelope:

```json
{
  "transport": { "type": "tcp", "host": "192.168.0.50", "port": 9100 },
  "mode": "receipt",
  "job": {
    "storeName": "OJO Store",
    "items": [{ "name": "Coffee", "quantity": 2, "unitPrice": 3.5 }],
    "cut": true
  }
}
```

Run:

```bash
ojo-print job --json job.json
```

Preview generated bytes instead of printing:

```bash
ojo-print job --json job.json --preview > out.bin
ojo-print label --ip 0.0.0.0 --json label.json --preview
```

Raw TSPL:

```bash
ojo-print raw --ip 192.168.0.50 --protocol tspl --text $'SIZE 50 mm,20 mm\r\nGAP 3 mm,0\r\nCLS\r\nTEXT 20,20,"3",0,1,1,"Hello"\r\nPRINT 1,1\r\n'
```

Raw ESC/POS hex:

```bash
ojo-print raw --ip 192.168.0.50 --hex '1b 40 48 65 6c 6c 6f 0a'
```

## Media size

No reliable standard query reports installed receipt width or label size.

- ESC/POS status can report online/paper/error state, not roll width.
- TSPL can calibrate gap/black mark, but label width is not sensed and calibrated size is usually not returned over raw TCP.

Store media settings in config. Use `width-test` if receipt width is unknown. Use `calibrate-label` after changing label rolls.
